3. POSIX TCP Socket Syscall Lifecycle

TCP Server Lifecycle

  1. getaddrinfo() - Resolve bind address
  2. socket() - Get listening socket FD
  3. setsockopt(SO_REUSEADDR) - Prevent address locked bug
  4. bind() - Assign IP + Port to socket
  5. listen() - Mark socket as passive queue
  6. accept() - Block until client connects -> returns client FD
  7. recv() / send() - Read/Write binary stream
  8. close() - Teardown connection

TCP Client Lifecycle

  1. getaddrinfo() - Resolve server hostname/IP
  2. socket() - Create communication endpoint
  3. connect() - Initiate 3-way TCP handshake
  4. send_all() - Send structured payload loop
  5. recv() - Read server response
  6. close() - Terminate socket
